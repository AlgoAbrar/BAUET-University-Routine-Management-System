# Medium Showcase Dataset

This is a deliberately reduced, real-data subset of the full CSE timetable. It contains 10 course offerings and 21 weekly meeting events across batches 21 and 22. The CSVs are generated by `build_medium_dataset.py`; the catalog `courses.csv` is copied byte-for-byte from `data/input/courses.csv`.

It covers the key project behaviors without attempting the unverified full 52-offering instance:

- Batch 21 has 64 students, so theory must use Room 202.
- The two explicit batch-21 parallel lab pairs are retained.
- Lab patterns include 1.50-credit / 3-hour labs (two weekly three-period meetings), a 0.75-credit / 1.50-hour lab (one three-period block), and a 1.00-credit / 2-hour lab (one two-period block).
- Shared theory, fixed lab-teacher pairs, teacher workloads, room suitability, and clash prevention are exercised.
- For theory, one course offering may use at most two periods on any day. The solver minimizes same-day pairs as a soft preference, so it prefers three distinct days when feasible. Required multi-period lab blocks are exempt from this theory-only cap.

From the project root, run:

```bash
python main.py --solve --csv-only --input-dir data/medium_test --output-dir data/medium_output --timeout-seconds 600
```

The verified CSVs are written to `data/medium_output/`. The 600-second value is a timeout ceiling, not a runtime guarantee; actual solve time depends on the machine and solver version. The separate full dataset remains in `data/input/`.
